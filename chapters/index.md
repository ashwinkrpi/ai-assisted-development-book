# AI Assisted Development Book — Volume 1

### *Part 1: Foundations of AI-Assisted Software Development*

> **AI is a force multiplier — not a replacement for engineering judgment.**

This book teaches you how to use AI tools to write software while keeping the practices that make software reliable: clear requirements, small steps, automated tests, and human review. Volume 1 covers the foundations, from what AI-assisted development is through building your first complete project with it.

## Who this book is for

Developers who have written some code but are new to using AI tools in their work. You don't need any background in AI or machine learning.

The examples use basic Python, git and the command line. If any of those are new to you, these free resources cover what you need:

- **Python:** [the official Python tutorial](https://docs.python.org/3/tutorial/)
- **Git:** [*Pro Git*, chapters 1–3](https://git-scm.com/book/en/v2)
- **The command line:** [MDN's command line crash course](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Command_line)

New to AI tools? Start with [Chapter 0 — Before You Begin](00-before-you-begin.md). Unfamiliar terms are defined in the [Glossary](glossary.md).
