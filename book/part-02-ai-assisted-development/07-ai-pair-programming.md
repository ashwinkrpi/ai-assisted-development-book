# Chapter 7 – AI Pair Programming

## Learning Objectives
- Use AI as a pair programmer.
- Work iteratively.
- Review AI output.

## Workflow
1. Clarify requirements.
2. Design.
3. Generate one component.
4. Test.
5. Review.
6. Repeat.

## Prompt Card

```text
Act as my senior pair programmer. Clarify requirements, explain trade-offs, generate only the next step, then wait for review.
```

## Mini Lab
Build a REST endpoint using AI one step at a time.

## Summary
AI pair programming is a collaborative workflow that combines AI speed with human judgement.
