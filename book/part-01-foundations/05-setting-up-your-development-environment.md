# Chapter 5 – Setting Up Your AI-Assisted Development Environment

> *A productive AI-assisted workflow starts with a well-configured development environment.*

## Learning Objectives

After this chapter you will be able to:

- Select appropriate AI development tools.
- Configure a modern development environment.
- Integrate AI into your editor, terminal and version control workflow.
- Protect secrets and sensitive data when using AI tools.

---

## 1. Choosing Your Toolchain

A typical AI-assisted development workstation includes:

| Category | Examples |
|----------|----------|
| Editor | VS Code, IntelliJ IDEA |
| AI Assistant | ChatGPT, Codex, GitHub Copilot |
| Terminal | Bash, PowerShell, Zsh |
| Version Control | Git |
| Build Tools | Maven, Gradle, npm, pip |
| Containers | Docker |

Choose tools that integrate naturally with your existing workflow.

---

## 2. Core Setup

Recommended steps:

1. Install Git.
2. Install your preferred IDE.
3. Configure a modern terminal.
4. Enable AI extensions.
5. Configure language formatters and linters.
6. Create a sample project to verify the environment.

---

## 3. Integrating AI into Daily Work

Use AI to:

- Explain compiler errors.
- Generate boilerplate.
- Draft unit tests.
- Review pull requests.
- Create documentation.

Avoid using AI as an automatic replacement for code review.

---

## 4. Secure Usage

Never paste:

- Production secrets
- API keys
- Customer data
- Confidential source code (unless permitted by your organisation)

Always understand your organisation's AI usage policy.

---

## 5. Version Control

Keep AI-generated changes small.

Recommended workflow:

1. Generate code.
2. Review manually.
3. Run tests.
4. Commit focused changes.
5. Open a pull request.

---

## 6. Developer Checklist

- IDE configured
- Git installed
- AI assistant available
- Formatter enabled
- Linter enabled
- Test runner configured

## Summary

A well-configured development environment allows AI to become a natural part of the software engineering workflow. Productivity comes not from a single tool but from the integration of editors, version control, testing, automation and AI assistance.
